
# 🧥 HOODLY | Essential Comfort

**HOODLY** is a minimalist, creative e-commerce landing page designed for a high-end hoodie brand. The design focuses on "warm-to-the-eye" aesthetics, using a soft palette and high-quality model imagery to create a cozy, premium shopping experience.

---

## ✨ Features

- **Minimalist Design:** Clean layout with plenty of white space to reduce cognitive load.
- **Warm Color Palette:** Uses soft creams (`#FAF9F6`), clay oranges, and mocha browns.
- **Interactive UI:** - Smooth scrolling for navigation.
    - "Quick Add" hover effects on product cards.
    - Dynamic cart counter using Vanilla JS.
- **Responsive Layout:** Fully optimized for mobile, tablet, and desktop screens.
- **Model-Centric:** Layout specifically designed to showcase photography of models wearing the products.

---

## 🎨 Design System

| Element | Color | Hex Code |

| **Accent** | Muted Clay | `#D27D2D` |
| **Typography** | Soft Charcoal | `#3E3636` |
| **Card Fill** | Light Sand | `#F3EFE0` |

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure for SEO and accessibility.
- **CSS3:** Custom properties (variables), Flexbox, and CSS Grid.
- **JavaScript:** Vanilla JS for DOM manipulation and interactive elements.
