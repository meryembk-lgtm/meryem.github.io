HOODLY | Minimalist Apparel
HOODLY is a premium, minimalist clothing brand focused on the intersection of comfort and modern geometry. This repository contains the front-end source code for the HOODLY web experience, designed to showcase a curated collection of high-quality hoodies.

🎨 Design Philosophy
The website mirrors the HOODLY logo:

Color Palette: Deep Maroon (#8B1A24), Slate, Onyx, and Sand.

Typography: Bold, geometric sans-serif for a strong, structural feel.

Layout: High use of negative space (white space) to let the product imagery breathe.

🚀 Features
Minimalist Interface: A distraction-free shopping experience.

Scroll Reveal Animations: Smooth JavaScript-powered entry effects for product cards.

Responsive Grid: Fully optimized for Mobile, Tablet, and Desktop viewing.

Glassmorphism Navigation: A sleek, blurred header that stays fixed as you browse.

🛠️ Installation & Usage
Clone the project:

Bash

git clone https://github.com/yourusername/hoodly.git
Open the site: Simply open index.html in any modern web browser (Chrome, Safari, Firefox).

Customization: To change the brand color to a different shade of red, update the --brand-maroon variable in the :root section of style.css.
